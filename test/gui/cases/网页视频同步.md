# 网页视频同步

前置：TC-P-001/002 通过（A 建房、B 已加入并跟随）。测试站点首选 bilibili（无需登录、视频页自动起播）；如需验证 cycani，先跑自动登录：`node test/tools/cycani-login.cjs`（账号见 account.md）。

注意事项（实测教训）：
- 测试视频要避开结尾：bilibili 播完会**自动连播**切到推荐视频（URL 变化、video 元素被换），seek/对齐断言会全部失真——先 eval seek 到视频前 1/3 处再开始断言
- 多页签共存时（连播残留等）读状态必须带 `--url=<视频URL子串>` 精确定位 target，否则 `video-drive` 取第一个匹配页签会张冠李戴
- 改过前端代码后必须**完全重启实例**再跑同步用例：HMR 重挂载会泄漏旧 controller 的 followTimer，产生"暂停同步不生效"的假象（生产构建无 HMR 不受影响）

视频页操作：壳的 cdp MCP 只绑壳 page，网页页签是独立 CDP target——读播放状态用 `node test/tools/video-drive.cjs <9222|9223> status`，点视频（播放/暂停）用 `click-video`（输入级真实鼠标事件）；进度条拖拽坐标不稳，seek 步骤允许 eval 注入 `currentTime`（seek 事件语义与用户拖动等价）。
